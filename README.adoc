== Description
Embedded Development Framework (EDF) is a collection of libraries intended for use in embedded systems. It consists of the core library of platform independent building blocks, peripheral interfaces, drivers for specific ICs and common circuits.

== Installation
EDF is a standard CMake library. Include it via `FetchContent` or as a local directory, then link to what you need (`EDF`, `Peripherals`, or `Drivers`).

[source,cmake]
----
include(FetchContent)
FetchContent_Declare(
    EDF
    GIT_REPOSITORY https://github.com/AdamVeazey/edf.git
    GIT_TAG        v1.0.1
)
FetchContent_MakeAvailable(EDF)

target_link_libraries(your_target PRIVATE EDF)
----

*(Note: If you use Zephyr include EDF as a standard module in your project workspace).*

=== CMake Options Reference
When configuring EDF, you can toggle these options:

* `-DEDF_BUILD_PERIPHERALS=ON`: Build peripheral interface definitions.
* `-DEDF_BUILD_DRIVERS=ON`: Build specific hardware drivers (auto-enables peripherals).
* `-DEDF_BUILD_EXAMPLES=ON`: Build example applications.
* `-DEDF_BUILD_TESTS=ON`: Build the GoogleTest unit test suite.
* `-DEDF_ENABLE_LTO=ON`: Enable Link-Time Optimization for smaller binaries.
